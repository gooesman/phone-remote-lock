# phone-remote-lock · 手机遥控器

在电脑上控制 **小米 15 Pro**（或任意 Android 手机）：锁屏、音量、亮度、刷视频上下翻，
还有一个**手机形状的映射层矩形**（可黑可白、透明度可调）——用电脑鼠标直接当手机触摸屏用。

不装手机端 App、不需要 root、不需要数据线。

---

## 一、原理

全部走 **adb 无线调试**，电脑发指令、手机执行系统级动作：

| 功能 | 实现 |
|---|---|
| 锁屏 | `input keyevent 223`（KEYCODE_SLEEP，立即休眠 → 按系统设置进入锁屏） |
| 音量 ±、静音 | `input keyevent 24 / 25 / 164` |
| 播放暂停 | `input keyevent 85` |
| 亮度 步进 | `input keyevent 221 / 220`（走系统亮度键通路，能穿透应用窗口覆盖） |
| 亮度 绝对值 | `settings put system screen_brightness <0-255>`（持久化，重启后保留） |
| 刷视频 / 触摸 | `input swipe` / `input tap`，坐标按当前旋转后的分辨率换算 |
| 返回 / 桌面 | `input keyevent 4 / 3` |

## 二、手机端一次性设置（小米 15 Pro / HyperOS）

### 1. 打开开发者选项
设置 → 我的设备 → 全部参数与信息 → 连点 **「OS 版本」7 次**。

### 2. 打开两个调试开关（**这一步最关键**）
设置 → 更多设置 → 开发者选项：

- ✅ **USB 调试**
- ✅ **USB 调试（安全设置）** ← 不开这项，`input` 命令会**静默失效**：命令返回成功，但手机毫无反应

> 「USB 调试（安全设置）」需要**插着 SIM 卡 + 登录小米账号**才能打开。
> 建议顺手打开 **「停用 adb 授权超时」**，否则过几天要重新授权。

### 3. 打开无线调试
设置 → 更多设置 → 开发者选项 → **无线调试** → 打开 → 点进「无线调试」页 → **使用配对码配对设备**。
会看到 **IP:配对端口** + **6 位配对码**（配对用，一次性）；
配对完后同一页还有 **IP:调试端口**（连接用，**端口号和配对端口不一样**）。

### 4. 保证息屏即锁屏
设置 → 锁屏 → **自动锁定 → 立即**。

## 三、电脑端安装

```
双击 setup.bat      # 建虚拟环境 + 装依赖（只跑一次，含 PySide6-Essentials 约 120MB）
```

启动方式：

| 方式 | 说明 |
|---|---|
| **start.bat** | 常驻托盘 + 全局热键（推荐） |
| **connect.bat** | 手动输入 IP:端口 连接手机（连不上会引导配对） |
| **overlay.bat** | 黑色半透明鼠标映射层 |
| **remote.bat** | 数字菜单遥控面板 |

### 手动连接（输入 IP 和端口）

不想记命令的话，直接双击 **`connect.bat`**，它会把手机上的地址要过来：

```
   连接手机（无线 adb）
   手机端：设置 → 开发者选项 → 无线调试（打开）
   页面顶部显示的 IP:端口 就是要填的地址，例如 192.168.1.23:42007
   提示：刚换过 Wi-Fi、或者提示 offline / 连不上时，
         手机「无线调试」页 →「使用配对码配对设备」走一次配对最省事。
   ----------------------------------------------------
   自动发现到设备 : 192.168.1.23:42007
   上次保存的地址 : 192.168.1.23:38511（不在本机当前网段，多半已失效…）
   请输入 手机IP:端口（直接回车用 192.168.1.23:42007）: _
```

- 会先用 mDNS 探一次，发现到就把地址填好当默认值；直接回车即用。
- 只输 `42007`（端口）或只输 `192.168.1.23`（IP）也能识别，缺的一半自动补上。
- 上次保存的地址如果不在本机网段（换了 Wi-Fi 的典型情况），会直接标注"多半已失效"。
- 连接成功才会把地址写进 `config.json`；失败不会污染配置。

**连不上时直接进配对流程**（不用先返回再重来）：

```
   连接失败。要用「配对码」重新配对再连一次吗？
   手机上打开「无线调试」→「使用配对码配对设备」，会显示 端口 + 6 位配对码。
   [Y] 现在配对 / [n] 退出（直接回车 = 配对）: 
   把手机上的「配对端口」和「配对码」填进来；
   也可以一次整行粘进来，例如：192.168.1.23:44667 123456
   配对 IP:端口 + 配对码: 192.168.1.23:44667 123456
```

- **回车就是配对**（默认 Y），不用输入 y。
- 配对端口 + 配对码可以**一次整行粘贴**，也支持只给端口、只给 IP。
- 配对成功后会自动用手机当前端口再连一次，失败还会自动换个端口重试。
- 配对失败会提示最常见的两个原因：配对码过期（弹窗关了要重开）、把"连接端口"当成"配对端口"填了。

> 配对端口只在手机「使用配对码配对设备」弹窗打开期间有效，且和连接端口不是同一个，所以没法全自动——
> 但上面这套流程已经把这步压缩成"粘一行"。

命令行等价写法：

```
.venv\Scripts\python.exe lock_phone.py connect                # 同上，引导式输入
.venv\Scripts\python.exe lock_phone.py connect 192.168.1.23:42007   # 直接连这个地址
```

托盘图标右键菜单里也有「连接手机（IP:端口 / 配对码）」，会开一个控制台窗口跑同一套引导。

> 这个控制台窗口是通过 `CREATE_NEW_CONSOLE` 拉起来的，父进程是 pythonw.exe（没有标准句柄），
> 早期版本会出现满屏乱码。现在 `_fix_console_encoding()` 会做两件事：
> ①句柄不可用时重新打开 `CONOUT$` / `CONIN$`；②把控制台代码页和 Python 的流编码
> 一起对齐到 UTF-8，中文提示正常显示。

### 首次配对

**先把手机上的端口查出来**（别抄手机上那串，无线调试的端口每次开关都会变）：

```
.venv\Scripts\python.exe lock_phone.py discover
```

输出会分成两行，注意**配对端口和连接端口是两个不同的端口**：

```
  [连接] adb connect 192.168.1.23:42007
  [配对] adb pair 192.168.1.23:44667 <6位配对码>
```

`[配对]` 只在手机上打开「使用配对码配对设备」弹窗时才会出现（弹窗一关端口就失效）。

然后：

```
.venv\Scripts\python.exe lock_phone.py pair 192.168.1.23:44667 123456
```

配对成功后工具会记住设备，之后自动连接，并用 mDNS 自动跟踪端口变化。

### 换了 Wi-Fi / 换了网段之后

手机 IP 变了不用改配置——直接：

```
.venv\Scripts\python.exe lock_phone.py status
```

它会先试旧地址，失败就用 mDNS 重新发现，成功后**自动把新地址写回 config.json**。
如果手机完全找不到，会提示你去手机上重开「无线调试」。

也可以手动指定新地址：

```
D:\adb\platform-tools\adb.exe connect 192.168.1.23:42007
```

或直接改 `config.json` 里的 `device` 字段。

## 四、托盘图标：主入口

托盘图标（`start.bat` 启动后出现在任务栏右下角）是主要入口：

| 操作 | 效果 |
|---|---|
| **左键单击** | **打开控制面板 + 映射层**（默认；可在 config 的 `left_click` 里改成只开面板 / 只开映射层 / 不响应） |
| 右键单击 | 完整菜单（面板、锁屏、映射层开关、音量、亮度、刷视频、导航、重连、退出） |

托盘程序带**单实例锁**：重复运行不会出现两个图标（避免热键被触发两次）。
要重启就先在菜单里点「退出」，再运行 `start.bat`。

## 五、控制面板

一个小窗口，按钮直接作用于手机，不用记快捷键：

- **亮度 · 系统（退出全屏后生效）**：减 / 加 / 10% / 50% / 100%
- **亮度 · 当前 App 全屏（滑动调）**：调暗 / 调亮（走全屏里的滑动手势，不动系统亮度）
- **音量**：减小 / 增大 / 静音
- **播放 / 刷视频**：上一个 / 播放暂停 / 下一个
- **长按 / 倍速**：倍速（长按中心）/ 长按 3 秒 —— 抖音、B站的长按倍速就是这么触发的
- **屏幕**：锁屏 / 唤醒 / **解锁**
- **全屏内滑动**：App 亮度（左侧）/ App 音量（右侧）/ 横屏进度
- **左上角**：`⚙ 设置`（快捷键绑定）+ **模式下拉**（B站竖屏 / 抖音 / B站横屏）
- **播放 / 换视频**：上一个 / 播放暂停 / 下一个 / 点赞　**长按 / 倍速**：倍速开关 / 长按一下
- **导航**：返回 / 桌面 / 任务切换
- **映射层**：开启 / 关闭（按钮会显示当前状态）
- **刷新状态 / 重新连接 / 输入地址连接**（`输入地址连接` 会弹框让你填 IP:端口）

面板顶部会实时显示设备连接状态和当前亮度；如果检测到有 App 占用窗口级亮度覆盖，会直接标出来。

面板由 `panel.py` 承载，是**单实例**的（用 `127.0.0.1:59731` 做锁），
重复唤起只会把命令转给已经在跑的那个，不会多开。
关掉面板窗口只是隐藏，托盘图标可以再唤起。

### 左上角「⚙ 设置」：改快捷键

面板**左上角**有个「⚙ 设置」按钮，点开就是快捷键绑定表：

```
功能 ▾ │ 快捷键（点这一格后直接按键） │ 操作
锁定手机 │ Ctrl+Alt+L              │ [删除]
音量 +   │ Ctrl+Alt+Up             │ [删除]
...
[添加绑定] [恢复默认]                          [保存] [取消]
```

- **改键**：鼠标点进「快捷键」那一格，直接按你想用的组合键就录进去了（不用手输）。
- **加/减**：`添加绑定` 加一行，选功能 + 按键；`删除` 删掉某一行；`恢复默认` 回到出厂那套。
- **校验**：重复的快捷键、认不出来的按键会拦下来；没带 Ctrl/Alt/Shift 的单键会先警示
  （这种会全局抢占键盘，打字容易误触）；留空 = 不绑定，全部清空会二次确认。
- **生效**：保存写入 `config.json` 的 `actions`。**托盘在跑的话约 2 秒自动重载，不用重启**；
  托盘没跑会在面板上提示你先启动 `start.bat`。

> 原理：快捷键由托盘进程用 pynput 注册（面板只负责写配置），托盘里有个 2 秒轮询
> `config.json` mtime 的守望线程，发现变化就停掉旧监听、按新配置重新注册，
> 并刷新托盘菜单文案。

## 六、鼠标映射层（手机形状的矩形，可黑可白）

**窗口本身就是一块和手机等比例对应的矩形**——不再是全屏遮黑，矩形以外完全透明、
桌面照常可见可点（窗口被裁成矩形形状，连鼠标都穿透过去）。

- **底色可切**：`T` 键在黑 / 白之间切换；**不透明度可调**：`[` / `]` 按 0.05 步进。
  两处改动都会写回 `config.json`（`overlay_color` / `overlay_alpha`），下次打开保持。
- 窗口仍带标题栏，可以随便拖动 / 缩放；矩形按手机长宽比自动居中，手机转屏后按 `R` 重读。
- 矩形内会画淡淡的九宫参考线（辅助瞄准），边框在"映射中"会变亮。

### 要按住右键才映射（防误触）

默认**按住鼠标右键**才进入映射状态，松开就退出：

| 操作 | 效果 |
|---|---|
| **按住右键** | 进入映射（左上角显示「映射中 ●」，边框变亮） |
| **右键快按一下**（< 250ms） | 返回键 |
| 按住右键 + **左键单击** | tap 点按 |
| 按住右键 + **左键拖动** | swipe 滑动（刷视频 / 翻页） |
| 按住右键 + **左键按住不动** | 长按（超过 `long_press_ms`，默认 600ms） |
| 按住右键 + **滚轮上/下** | 上一个 / 下一个视频 |
| 按住右键 + **中键** | 回到桌面 |

> 不按住右键时左键点击不会作用到手机（只显示"按住鼠标右键才能操作手机"）。
> 不想这样可以在 `config.json` 里把 `map_requires_right` 设为 `false`（恢复成随时可点）。

**鼠标光标是橙色小球**（映射中会多一圈外环），随鼠标实时显示，
不用十字线——十字线在高频移动下会闪、会"画着画着就没了"。

**手机端只用安卓自带的触摸圆点**：映射层打开时开启开发者选项里的
「显示点按操作反馈」(`show_touches`)，点哪儿亮哪儿；**不用「指针位置」那个十字线**
（它会自己消失）。关闭映射层时自动还原。不想要可以 `overlay_pointer: false`，或按 `P` 临时开关。

### 性能

鼠标事件只记录坐标，重绘统一按 `overlay_fps`（默认 30fps）节流；状态轮询 200ms 一次。
1000Hz 的游戏鼠标也不会把绘制打满、更不会出现残影。

### 键盘快捷键（不受"按住右键"限制）

| 按键 | 效果 |
|---|---|
| **F** | **倍速开关**（按一下开、再按一下关） |
| **G** | 长按一下（1.2 秒，同点 swipe，App 认这个） |
| **U** | 一键解锁手机 |
| **空格** | 播放 / 暂停 |
| **↑ / ↓** | 音量 + / − |
| **← / →** | 系统亮度 + / −（退出全屏后生效的那个） |
| **Shift + ← / →** | App 亮度（全屏里**左侧**上下滑那条通道） |
| **Shift + ↑ / ↓** | App 音量（全屏里**右侧**上下滑） |
| **L / W** | 锁屏 / 唤醒 |
| **B / H** | 返回 / 桌面 |
| **N** | 通知栏 |
| **T** | 底色 黑 / 白 切换（写回 config） |
| **[ / ]** | 不透明度 − / +（写回 config） |
| **P** | 手机触摸圆点 开 / 关 |
| **S** | 刷新状态（含亮度覆盖提示） |
| **R** | 重新读取分辨率（手机转过屏后用） |
| **F11** | 全屏 / 窗口切换 |
| **Esc** | 关闭映射层 |

### 长按 / 倍速播放

抖音、B站这类短视频的倍速是「**长按画面**」触发的（按住 2x，松开回 1x）。

- 走的是 `input motionevent DOWN/UP`（Android 11+），是**真正的按住不放**，不是同点滑动模拟，
  所以按住多久就倍速多久，松开立刻恢复。System 不支持时会自动退化成同点 `swipe` 长按。
- **映射层里按 `F` 并按住**：直接在屏幕正中心长按（横屏/竖屏都按当前 `cur=` 尺寸取中点）。
- **映射层里鼠标按住不动**：在光标所在位置长按，位置自己选（`F` 是固定的正中心快捷方式）。
- **控制面板**里有「倍速（长按中心）」「长按 3 秒」两个按钮。
- **托盘菜单**刷视频 → 倍速播放（长按屏幕中心）。
- **命令行**：`lock_phone.py long-press`（默认 1.2 秒）或 `long-press 2000` 指定毫秒。
- 自动抬起的兜底：按住超过 `long_press_max_ms`（默认 4 秒）会自动松手，
  退出映射层时也一定会抬起，不会在手机上残留一个按下的手指。

相关配置：

| 键 | 默认 | 说明 |
|---|---|---|
| `long_press_ms` | 600 | 鼠标按住多久算长按 |
| `long_press_hold_ms` | 1200 | 面板/热键触发时的长按时长（毫秒） |
| `long_press_max_ms` | 4000 | 按住不放的自动松手上限 |

透明度在 `config.json` 的 `overlay_alpha` 里调（0.05 近乎透明，1.0 全不透明），
也可以在映射层里直接按 `[` / `]` 调、按 `T` 切黑白。
不想要映射层时，用 `left_click: "panel"` 只留控制面板，或在托盘菜单里点「映射层 → 关闭」。

> **注意**：这不是屏幕镜像，看不到手机画面，是盲操作。
> 想要「看得见手机屏幕 + 实时鼠标控制」，请用 **scrcpy**（另一套工具，效果更好但需要单独安装）。

## 七、使用模式（B站竖屏 / 抖音 / B站横屏）

**不同 App、不同方向，手势完全不一样**，所以面板左上角「⚙ 设置」旁边有个模式下拉：

| 模式 | 换视频 | 暂停/播放 | 其它 |
|---|---|---|---|
| **哔哩哔哩 · 竖屏** | 上滑 = 下一个 | 双击 | 下滑 = 上一个；双击 = 暂停；长按 = 倍速 |
| **抖音 · 竖屏** | 上滑 = 下一个 | **单击** | 双击 = 点赞；长按任意处 ≈1s = 倍速浮层 |
| **哔哩哔哩 · 横屏** | **点控件里的「下一个」** | 双击 | 左右滑 = 进度；左上下滑 = 亮度；右上下滑 = 音量 |

切换模式会写进 `config.json`（`mode`），托盘会自动热重载，按钮和快捷键的行为立刻跟着变。

### 横屏为什么不能上滑换视频？

因为横屏全屏里，**上下滑已经被亮度和音量占用了**（B站：左侧=亮度、右侧=音量），
B站没有给"上一条/下一条"留滑动手势。所以本工具的做法是：

1. 先单击屏幕中间唤出播放控件；
2. 用 `uiautomator dump` 把界面 UI 树拉下来，找到文字/描述里含
   **「下一个」「下一个视频」「下一集」「下一P」** 的按钮；
3. 点它的中心坐标。

找不到就说明这条视频不在合集/连播里（普通单集视频本来就没有"下一个"），
工具会如实告诉你。也可以退出全屏、在竖屏流里上滑换视频。

### 倍速：开关 + 长按

- **倍速开关**（推荐）：按一下 = 开始按住不放（抖音/B站的长按倍速就起来了），
  再按一下 = 松开恢复正常速度。映射层按 **`F`**，面板有「倍速开关」按钮，
  命令行 `speed-toggle`。
- **长按一下**：按一次固定长按 1.2 秒（映射层 `G`，面板「长按一下」，命令行 `long-press-once`）。
- 技术上：**同一个点上的 `input swipe` 才是 App 认的长按**；用 `input motionevent` 分两次发
  DOWN / UP 时 App 经常识别不出来（所以早期版本"长按没反应"）。
  倍速开关因此走 `motionevent DOWN` + 每 0.5 秒补一个 `MOVE` 心跳，直到你关掉它。
- **兜底**：按住超过 `speed_hold_max_ms`（默认 120 秒）会自动松开；退出映射层也一定会松开，
  不会在手机上残留一个按下的手指。

## 八、一键解锁手机

托盘菜单 / 面板「解锁」按钮 / 映射层 `U` / 命令行 `unlock`：

1. 先 `keyevent 224` 唤醒屏幕；
2. 上滑（0.5, 0.86 → 0.5, 0.28）拉起密码盘；
3. 如果 `config.json` 里填了 `unlock_pin`，就 `input text <PIN>` + 回车；
4. 再查一次锁屏状态，如实报告成功/失败。

```json
{ "unlock_pin": "1234" }
```

**注意**：

- `unlock_pin` 是明文存在 `config.json`，而这个文件已被 `.gitignore` 排除，不会被提交。
- **有些 ROM 的安全锁屏会拒绝注入的文本**（防的就是自动化工具）。这种情况本工具会直接告诉你，
  并建议改用小米自带的「**蓝牙设备解锁**」（设置 → 锁屏与密码 → 蓝牙设备解锁）
  或 Google Smart Lock（贴身解锁）——这两个在锁屏状态下也能直接进桌面。
- 没设安全锁（只上滑）的手机，第 2 步就解锁了，不需要 PIN。

## 十、亮度：两套通道，别搞混

Android 13 之后的亮度是**三层叠加**的，从下往上优先级递增：

| 层级 | 设置方式 | 特点 |
|---|---|---|
| 1. 用户亮度设置 | `settings put system screen_brightness 0-255` | 持久化，重启保留 |
| 2. 系统级覆盖 | `cmd display set-brightness 0.0-1.0` | 临时覆盖，可能钉住到重启 |
| 3. **应用窗口级覆盖** | 抖音/B站**播放器的亮度手势** | **优先级最高，压住前两层** |

所以实际是**两套亮度、两条通道**，本工具把它们分开做：

| | **系统亮度**（第 1 层） | **App 亮度**（第 3 层） |
|---|---|---|
| 什么时候可见 | 桌面、普通 App；**退出 B站全屏后**就是这个值 | **只有 App 全屏时**（B站横屏播放器） |
| 怎么调 | 映射层 `←` / `→`；面板「亮度 · 系统」；CLI `bright-up/down`、`bright 60%` | 映射层 `Shift+←` / `Shift+→`；面板「亮度 · 当前 App 全屏」；CLI `app-bright-up/down` |
| 底层动作 | `input keyevent 221/220`（能穿透覆盖）或 `settings put` | **模拟左侧上下滑手势**（B站/抖音都是左=亮度、右=音量） |
| 退出全屏后 | 就是这个值 | 消失，回到系统亮度 |

一句话：**B站全屏里看到的不是系统亮度**，那个是 B 站自己的窗口亮度，只能用滑动去调；
你在工具里设的系统亮度会在**退出全屏时**显现出来。

- `bright-get`（面板刷新状态）会明确告诉你现在有没有 App 在全屏占用、以及系统亮度是多少。
- **安全阀**：如果当前没有 App 占用窗口亮度，"App 亮度"的滑动**不会发出去**——
  否则这记上下滑在竖屏短视频里很可能被当成"切换视频"。
  确实需要硬发就把 `app_bright_require_override` 设成 `false`。
- 实测数据（小米 15 Pro / HyperOS / Android 16）：
  - 生效亮度 = `设置值 / 255 × 0.25`（0.25 是这块屏的常规亮度上限，再往上进 HBM 高亮模式）
  - 一次亮度键事件 ≈ 设置值 ±12
  - 滑动只改 App 那层，**系统亮度数值完全不变**（实测滑动前后都是 128/255）

排查命令：`lock_phone.py bright-get`，会一并告出占用覆盖的包名。

## 十二、常见问题

**Q：命令返回 `OK`，但手机完全没反应**
A：`USB 调试（安全设置）` 没开。小米特有开关，不开的话 `input` 系列命令全部静默失效。

**Q：手机息屏了但没上锁**
A：设置 → 锁屏 → 自动锁定 → **立即**。

**Q：亮度调了没反应**
A：先跑 `lock_phone.py bright-get`。如果提示某个 App 占用窗口亮度覆盖，那就是抖音/B站播放器的亮度手势压住了；
在播放器左侧把亮度手势滑回最大值，或退出播放器即可。步进调节（←→）不受这个影响。

**Q：鼠标映射层的点击位置不准**
A：先确认手机上能看到触摸落点圆点（映射层会自动开，按 `P` 可手动开关）；手机旋转后按一下 `R` 重新读取分辨率。映射是按当前 `cur=` 尺寸等比换算的，横竖屏都能用。

**Q：映射层里点了但没反应 / 反应慢**
A：每次手势都是一次 adb 调用，延迟约 100-300ms，属于正常。快速滚动时会排队列。
这不是实时镜像，要实时请看 scrcpy。

**Q：连接失败 / 过一会儿就断**
A：① 手机没开「无线调试」；② 不在同一 Wi-Fi；③ 端口变了。
跑 `lock_phone.py discover`，或托盘菜单点「重新连接」（会走 mDNS 自动发现）。

**Q：映射层报缺少 PySide6**
A：重跑 `setup.bat`，或 `.venv\Scripts\python.exe -m pip install PySide6-Essentials`。
（本项目只用 QtCore / QtGui / QtWidgets，`PySide6-Essentials` 就够，比完整 PySide6 省约 250MB；
如果你之前装过完整版 PySide6，卸载后可能残留 Addons 文件——用 `pip uninstall` 不会删干净，
可以按 pip 的 `RECORD` 清单核对残留。）
（托管 Python 3.13 不带 tkinter，所以这里用 Qt 实现。）

**Q：热键按了没反应**
A：检查 `Ctrl+Alt+方向键` 是否被 Intel 显卡的旋转热键占用；看 `lock_phone.log`。

**Q：托盘出现了两个图标 / 热键按一次触发两次**
A：旧版本没有单实例锁。双击 **`restart.bat`** —— 它会清掉所有旧的托盘/面板/映射层进程再重新启动一个。
新版本已经带单实例锁，重复双击 `start.bat` 不会再多开。

**Q：提示"无线调试连接已失效（offline）"**
A：说明手机端 adb 的 TLS 会话僵死了（网络本身可能是通的）。处理顺序：
1. 手机上：开发者选项 → **无线调试** → 关掉再打开（端口会变，本工具会自动重新发现）
2. 还不行就「取消配对」后用新的配对码重新 `pair` 一次
3. 本工具已经会自动做：断开重连 → mDNS 重新发现 → 重启本地 adb server（各一轮）

**Q：按钮点了要等一会儿才生效**
A：手机离线时每次操作都要走重连流程。工具加了失败冷却（`retry_cooldown`，默认 4 秒），
所以离线期间按钮会快速返回错误而不是卡住。手机在线时是 100-300ms 级别。

## 十三、体积与清理

- `lock_phone.log` 超过 512KB 会自动清空重写，不用手动管。
- 依赖只装 `PySide6-Essentials`（约 235MB 的 `.venv`），**不要装完整的 PySide6**——
  完整版会带 WebEngine（单个 DLL 194MB）、Qt3D、Charts、Designer 等，本项目一个都用不到。
- 如果之前装过完整版又卸掉了，**`pip uninstall` 不会删干净**，会残留 200MB+ 的孤儿 DLL。
  核对办法（pip 的 `RECORD` 是权威清单）：

  ```bat
  :: 列出 site-packages/PySide6 下不属于任何已安装包的文件
  .venv\Scripts\python.exe -c "import csv,os;sp=r'.venv\Lib\site-packages';owned={os.path.normpath(r[0]) for d in os.listdir(sp) if d.endswith('.dist-info') for r in csv.reader(open(os.path.join(sp,d,'RECORD'),encoding='utf-8',newline='')) if r};[print(os.path.join(sp,os.path.relpath(os.path.join(r,f),sp))) for r,_,fs in os.walk(os.path.join(sp,'PySide6')) for f in fs if os.path.normpath(os.path.relpath(os.path.join(r,f),sp)) not in owned]"
  ```
- 开发期的临时截图 / 诊断输出（`test-logs/`、`_tmp_*`、`shot_*.png`）都已清掉，这类文件记得别提交。

## 十四、备选方案：不想要 adb 的话

手机装 **MacroDroid**：
1. 新建宏：触发器 = **HTTP Server Request**（或 Webhook）
2. 动作 = **锁屏**
3. 电脑上 `curl http://<手机IP>:<端口>/lock` 触发

优点：重启手机不用重连、不依赖 adb。缺点：要装 App、要给辅助功能/设备管理员权限。
